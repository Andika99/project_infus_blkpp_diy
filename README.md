# project_infus_blkpp_diy

- menggunakan microcontroller ESP32
- menggunakan sensor load cell
- setting konfigurasi menggunakan WifiManager
- komunikasi menggunakan Wifi dan protokol MQTT

# Konfigurasi pin
- Tombol Tare - 15
- Tobol Wifi Provisioning (untuk setting) - 27
- Buzzer - 32
- Loadcell DOUT - 16
- Loadcell SCK - 4
- LCD 16x2 I2C (SDA) - 21
- LCD 16x2 I2C (SCL) - 22
